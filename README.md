엑셀과 수기로 흩어진 거래처·품목·재고·매출 정보를 한 곳에 모아,
작은 팀이 **빠르고 정확하게** 일할 수 있게 돕습니다. 사무실 내부에서만 쓰는 시스템이에요.

---

## 기능

- [ ] **거래처 관리** — 매입처·매출처 정보 등록 / 조회 / 수정 _(진행 중)_
- [ ] 로그인 / 직원 계정
- [ ] 품목 관리 — 취급 상품과 단가
- [ ] 재고 관리 — 입·출고와 현재 수량
- [ ] 매입 / 매출 관리
- [ ] 거래명세서 · 영수증 PDF 발행

# 1. 실행 (http://localhost:8080)
